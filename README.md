# helix coach bot

телеграм-бот: персональный бодибилдинг-тренер + учёт калорий + расшифровка анализов helix.

грубоватый саркастичный тренер на русском: ведёт онбординг, генерирует программу
тренировок под тебя, считает калории/бжу, разбирает анализы (ocr), строит графики
прогресса и напоминает тренироваться.

## возможности

- **онбординг**: пошаговый опрос (цель, пол, возраст, рост, вес, уровень, оборудование,
  частота, травмы, программа, время напоминаний, пищевые ограничения) + авторасчёт нормы
  калорий/бжу по формуле миффлина — сан жеора.
- **тренер**: генерация программы (openai, с офлайн-фоллбэком), коррекция техники по
  описанию боли, перестройка плана при пропусках/боли, запись тренировок, объём, 1ПМ (эпли).
- **питание**: учёт еды текстом через fatsecret + свои продукты/блюда, дневная норма и
  остаток, cheat-meals, генерация меню.
- **анализы helix**: загрузка фото/скрина/pdf (ocr) или ручной ввод, расшифровка с
  референсами и red-flag для критических отклонений, динамика по показателям.
- **графики**: вес, объём, сила, калории, анализы (matplotlib).
- **напоминания**: утреннее, pre-workout, чек-ин (apscheduler).
- **экспорт**: `/экспорт` — zip с csv (тренировки, замеры, питание, анализы, профиль).

## стек

python 3.11+, aiogram 3.x, aiosqlite, apscheduler, openai, fatsecret api, pytesseract/easyocr,
matplotlib.

## быстрый старт

```bash
cp .env.example .env
# впиши BOT_TOKEN (обязательно), по желанию OPENAI_API_KEY, FATSECRET_* 
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

без `OPENAI_API_KEY` бот работает на офлайн-шаблонах (программа, меню, расшифровка).
без `FATSECRET_*` бот просит добавлять продукты вручную через `/продукт`.

### ocr

для распознавания анализов нужен tesseract с русским языком:

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-rus poppler-utils
```

или включи `OCR_ENGINE=easyocr` (поддерживает кириллицу из коробки, но тяжелее) и
раскомментируй `easyocr` в `requirements.txt`.

## docker

```bash

docker compose up --build -d
```

## конфигурация

все секреты — в `.env` (см. `.env.example`). хардкода токенов нет. база — sqlite
(`data/bot.db`).

└── utils/             # parser, calc, text_gen
